Wireshark Display Filters - Target Machine
Target IP: 192.168.71.197

1. All traffic to/from target
ip.addr == 192.168.71.197

2. TCP traffic involving target
ip.addr == 192.168.71.197 && tcp

3. HTTP traffic to target
ip.addr == 192.168.71.197 && tcp.port == 80

4. Traffic going to target
ip.dst == 192.168.71.197

5. TCP SYN packets reaching target
ip.dst == 192.168.71.197 && tcp.flags.syn == 1 && tcp.flags.ack == 0

6. Established TCP packets
ip.addr == 192.168.71.197 && tcp.flags.ack == 1

7. Useful HTTP/target filter
ip.addr == 192.168.71.197 && tcp.port == 80

8. Optional: TCP traffic from target
ip.src == 192.168.71.197 && tcp

Notes:
- Enter these in Wireshark's Display Filter bar.
- Right-click a packet -> Follow -> TCP Stream to inspect one TCP conversation.
- Statistics -> Conversations -> TCP can summarize TCP conversations.
